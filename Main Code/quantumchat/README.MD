<h1 align="center">✦ <span style="background: linear-gradient(90deg, #ff512f, #f09819); -webkit-background-clip: text; color: transparent;">Features</span> ✦</h1>

<span style="background: linear-gradient(90deg, #ff9a9e, #fad0c4); -webkit-background-clip: text; color: transparent;">✦</span> **Real-time chat interface**: Create multiple chat rooms, add members, and send messages.

<span style="background: linear-gradient(90deg, #a1c4fd, #c2e9fb); -webkit-background-clip: text; color: transparent;">✦</span> **Shareable links**: Easily invite others to join your chats via unique links.

<span style="background: linear-gradient(90deg, #fbc2eb, #a6c1ee); -webkit-background-clip: text; color: transparent;">✦</span> **Learning Center**: Access interactive courses like French, Math, Spanish, Hindi, and Mandarin directly within the chat interface.

<span style="background: linear-gradient(90deg, #84fab0, #8fd3f4); -webkit-background-clip: text; color: transparent;">✦</span> **Course navigation**: Courses open inside the chat UI using an embedded iframe, with lessons and practice sections.

---

<h1 align="center">✦ <span style="background: linear-gradient(90deg, #36d1dc, #5b86e5); -webkit-background-clip: text; color: transparent;">How to Use</span> ✦</h1>

1. Open `QuantumChat.html` in your browser.
2. Click **+ New Chat** to create a chat room.
3. Select a chat to start sending messages.
4. Use the **Learning Center** on the sidebar to explore courses.
5. Click **Back** to return to your chat view.
